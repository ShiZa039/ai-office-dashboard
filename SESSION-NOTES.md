### 2. Перенос «вкусностей» ClaudeBar (коммит `61dffa7`, НЕ запушен)

Донор `_external/ClaudeBar/` (github.com/tddworks/ClaudeBar, macOS-виджет
квот, ~17 провайдеров) изучен, перенесено с атрибуцией:

- **Pace-модель** `src/usagePace.ts`: burn rate = used%/elapsed% окна,
  темп «горячо/по графику/с запасом», раннее предупреждение (burnRate>1.5
  и <50% остатка), предохранители <20%/100%. +`test/usagePace.test.ts`.
- **429-backoff** в `SubscriptionUsageWatcher`: honouring `Retry-After`
  (баг `Retry-After: 0` игнорируется), экспонента 60с→30мин. +тест.
- **UI**: pace tick на барах, лейбл темпа (en/ru), pace-aware цвет;
  алерты на деградацию квоты (`aiOffice.usage.degradationAlerts`);
  квоты `5h 12% · 7d 34%` в tooltip статус-бара.
- **`docs/USAGE-PROVIDERS.md`** — протокольный конспект донора: эндпоинты,
  client_id для рефреша, pace-формулы, дедуп токенов; таблица DEFERRED
  (рефреш токена, дедуп, таблица цен, другие провайдеры — с условиями
  активации) и OUT (curl-хуки, macOS-куки).

  расширение не поддерживает сессии соответствующего CLI (непроверенный
  парсер без аккаунта — пассив).
- Попутно исправлен docs-drift: README (en/ru) утверждали «usage — только
  Claude Code», хотя Kimi-панель уже работала.

**Не проверено живьём**: реальные API-запросы (Claude — другая машина,
