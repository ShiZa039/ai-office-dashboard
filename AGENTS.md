# Правила проекта AI Office

## Направление проекта

- Плагин развивается как мультимодельный: поддержка не только Claude Code, но и Kimi Code (и далее других агентов).

## Ветки

- Рабочая ветка на этом компьютере — `master`. Работа ведётся прямо в ней. CI слушает `master`; меняется модель ветвления — в том же коммите правятся триггеры CI (`gotcha-ci-wrong-branch`).
- Ветка `kimi-code` существует как историческая, ограничений на мержи нет.

## Моделенезависимость (ADR-0001)

- Этот файл — **единственная точка входа правил**. Ничего отсюда не дублируется в CLAUDE.md / KIMI_CODE.md; `KIMI_CODE.md` — строго Kimi-специфика (`gotcha-two-agent-configs`).
- Машинные гейты — только в хук-скриптах `hooks/emit-agent-event.{py,js}`: они общие для обоих CLI. Паритет py/js обязателен, его страхуют `test/emitAgentEvent.test.ts` + `test/emitAgentEventPy.test.ts`.
- JSONL-схема событий — версионируемый контракт. Её изменение = один коммит: оба скрипта + `src/eventParser.ts` + `HOOKS-DESIGN.md` §4 + тесты (`gotcha-feature-test-debt`).
- Ссылки на правила и грабли — только слагами (`gotcha-…`, названием пункта), никогда номером (`gotcha-renumbered-parent`).

## Module Map

- `src/extension.ts` — точка входа, команды, вебвью-провайдер.
- `src/hookConfig.ts` / `src/hookConfigKimi.ts` — чистая логика регистрации хуков (без `vscode`); клей с ФС/UI — `src/hookInstaller.ts`.
- `src/subscriptionUsage.ts` / `src/kimiUsage.ts` — OAuth-пробы квот планов (Claude/Kimi), 429-backoff; `src/usagePace.ts` — pace-модель (burn rate vs окно). Протоколы и боевой опыт: `docs/USAGE-PROVIDERS.md`.
- `hooks/emit-agent-event.{py,js}` — хук-скрипты, эмитят события в `~/.claude/agent-events.jsonl`; гейт аварийной остановки (`stop_gate`).
- `src/eventWatcher.ts` + `src/eventParser.ts` — приёмная сторона JSONL.
- `src/agentState.ts` / `src/agentRoster.ts` / `src/agentDetail.ts` — модель агентов на дашборде.
- `media/office.{html,js,css}` — вебвью (ванильный JS, строки UI — только через `package.nls*.json`).
- Глубокий разбор хуков: `HOOKS-DESIGN.md`. Триаж литании: `docs/ADR-0001-litany-triage.md`. Грабли: `docs/gotchas.md`.
- Порог-ориентир: файл за 400 строк — кандидат на наблюдение в этой карте; проверка: `wc -l src/*.ts media/*.js media/*.css hooks/* | sort -n` (`gotcha-god-files`).

## Работа с агентом

- **Опасные действия — письменно и с подтверждением**: удаление, перезапись, git-мутации, сеть, процессы. Сначала объяснить зачем и что сделает команда, потом запросить подтверждение.
- **Не переспрашивай и не угадывай**: если цель ясна и есть добро — доводи до конца; спрашивай только когда ответ меняет следующий шаг. Развилки — через AskUserQuestion.
- **Протокол отладки**: снаружи внутрь; не чинить первую попавшуюся причину; фикс подтверждать фактическим прогоном (тест/команда), а не предположением.
- **Багфикс = тест** в том же коммите. Тесты зеркалят `src/` в `test/`.
- **Секрет-гигиена**: секретов нет ни в коде, ни в JSONL (текст промпта туда не пишется), ни в рабочем каталоге.
- **Плейсхолдеры помечены** явно (`TODO`/`FIXME` + пояснение), черновые данные не уезжают как проверенные (`gotcha-placeholder-data`).
- **Версии**: SoT — `package.json`; бамп только по команде пользователя; перед бампом — чеклист по диффу и два зелёных (`npm run lint`, `npm test`).
- **Систематически нарушаемое правило — дефект системы**, а не людей: правило меняется, исключение пишется в самом правиле.
- Конфиги быстро меняющихся сервисов не воспроизводить по памяти — сверять с актуальной документацией (`gotcha-llm-stale-configs`).

## Ритуал закрытия сессии

Триггер-фраза: «сводка сессии». Если сводить нечего — сказать явно.

1. Сверить с кодом всё, что сессия могла сделать ложью: `HOOKS-DESIGN.md`, README, Module Map выше, `ROADMAP.md` (`gotcha-docs-drift`, `gotcha-phantom-tails`). Канонические имена проверять grep'ом по коду, не по памяти.
2. Закрытые пункты roadmap помечать двухфазно: сначала фикс-коммит, потом пометка с SHA.
3. Всё отложенное — письменно (в roadmap или `docs/gotchas.md`), молчаливого «потом» нет (`gotcha-silent-later`).
4. Новая грабля, куснувшая в сессии, — в `docs/gotchas.md` со слагом; кандидат на миграцию в мастер-литанию.
