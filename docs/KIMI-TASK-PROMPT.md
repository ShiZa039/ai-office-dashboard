## Промпт №2 — модели по субагентам, Kimi-часть

> Заготовка (написана 2026-08-11, после реализации учёта субагентов для Claude
> Code — сплит `byAgent` в счётчиках токенов). Вставить в Kimi Code CLI, открытый
> в этом репозитории, ПОСЛЕ (или вместе с) промптом №1: без парсинга
> Kimi-транскриптов делить их по агентам нечего.

Контекст для составителя (что уже сделано на Claude-стороне; Кими это
объясняется внутри промпта):

- Начиная с Claude Code ~2.1.215 субагенты пишутся не в основной
  `<slug>/<session>.jsonl`, а в отдельные файлы
  `~/.claude/projects/<slug>/<sessionId>/subagents/agent-<agentId>.jsonl`
  (рядом лежит `agent-<agentId>.meta.json` c `agentType`, `description`,
  `spawnDepth`).
- Каждая usage-строка субагента самодостаточна: `isSidechain: true`,
  `agentId`, `attributionAgent` (тип агента — "Explore", "general-purpose",
  кастомные имена ростера), `sessionId` РОДИТЕЛЬСКОЙ сессии, `cwd`,
  `message.model`, `message.usage`. Поэтому токены субагентов сами ложатся в
  правильную сессию/проект, как только сканер начинает читать эти файлы.
- `TokenScanner.listFiles()` обходит `<projectDir>/<dir>/subagents/*.jsonl`;
  ретайр удалённых файлов идёт по каталогу проекта (`projectDirOf`), т.к.
  прунинг сессии уносит весь `<session>/subagents/`.
- Модель данных: `AgentModelTotals extends ModelTotals { byAgent:
  Record<agent, ModelTotals> }`; ключ `''` = основная цепочка (и всё, что
  посчитано до появления сплита). Персист — `PersistedTokenState` version 3
  (v1/v2 мигрируют: всё под `''`). Снапшот отдаёт `byAgent: AgentSlice[]`
  (agent, totals, costUsd, byModel) для сессии и проекта.
- UI: в тултипах счётчиков секция «по агентам» (`agentBreakdown` в
  `media/office.js`), у каждого агента в скобках его модели. Секция
  скрывается, когда в скоупе только основная цепочка.

```
Проект: VSCode-расширение AI Office (этот репозиторий). Счётчики токенов умеют
делить расход по агентам (сплит byAgent): для Claude Code это работает через
attributionAgent в транскриптах субагентов
(~/.claude/projects/<slug>/<sessionId>/subagents/agent-*.jsonl). Твоя задача —
такой же сплит для Kimi Code. Работай поверх текущего master, ничего не ломая
в Claude-путях.

1. Исследование (дополни docs/KIMI-USAGE.md, на русском):
   - пишет ли Kimi Code запросы субагентов в транскрипты; где — инлайн в файле
     сессии (аналог старого isSidechain: true) или отдельными файлами (аналог
     <sessionId>/subagents/agent-*.jsonl);
   - какие поля атрибуции есть в usage-записях субагента: тип/имя агента
     (аналог attributionAgent), id агента, ссылка на родительскую сессию, cwd,
     model; есть ли meta-файл с agentType;
   - попадает ли расход субагентов в файл основной сессии (риск двойного
     счёта — проверь дедуп по message id / request id).
   Каждый факт подтверждай примером записи с диска (путь + фрагмент JSON).

2. Реализация (только если п.1 подтвердил данные):
   - src/tokenUsage.ts: научи сканер видеть kimi-файлы субагентов (расширь
     listFiles по образцу claude-ветки subagents/); в handleLine заполняй
     атрибуцию из kimi-поля (сейчас читается entry.attributionAgent — если у
     Kimi поле называется иначе, добавь фоллбэк, не меняя claude-путь);
     ключ '' зарезервирован за основной цепочкой — не клади в него субагентов;
   - если атрибуция есть только в meta-файле рядом с транскриптом — прочитай

   - context gauge (lastCtx) по-прежнему только по основной цепочке — записи
     субагентов в него попадать не должны;
   - тесты: расширь test/tokenUsage.test.ts по образцу секции "subagent
     transcripts are counted" (assert + временные файлы, без фреймворков) —
     учёт, сплит byAgent, ретайр удалённой сессии вместе с субагентами;
   - UI трогать не нужно: тултипы «по агентам» в media/office.js уже
     рендерят byAgent из снапшота, источник им не важен.
   Если у Kimi Code субагентных записей нет — зафиксируй это в
   docs/KIMI-USAGE.md и остановись, кода не пиши.

3. Гейты: npm test и npm run lint зелёные. Каталог hooks/ не трогать.
   Комментарии в src — на английском, в стиле соседнего кода. Один коммит
   вида "feat: kimi per-subagent token split (research + impl)".
```
