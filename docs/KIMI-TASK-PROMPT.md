# Промпт для Kimi Code — Kimi-часть счётчиков стоимости

> Заготовка на будущее (написана 2026-08-10, после релиза v0.18.0). Вставить в
> Kimi Code CLI, открытый в этом репозитории, когда появятся лимиты. Контекст:
> v0.18.0 добавила стоимость по ценам API, индикатор контекста и спарклайн —
> только для транскриптов Claude Code; Kimi-модели из $-оценок исключены
> (`priceForModel` возвращает для них null). Соответствующий пункт бэклога —
> ROADMAP «Идеи на потом» → «Цены Kimi-моделей».

```
Проект: VSCode-расширение AI Office (этот репозиторий). В v0.18.0 панель токенов
научилась считать стоимость по ценам API, заполнение контекста и спарклайн — но
только для Claude Code. Твоя задача — сделать то же для Kimi Code. Работай поверх
текущего master, ничего не ломая в Claude-путях.

1. Исследование (результат — новый файл docs/KIMI-USAGE.md, на русском):
   - где Kimi Code хранит транскрипты сессий на диске (аналог
     ~/.claude/projects/<slug>/<session>.jsonl) и хранит ли вообще;
   - формат записей: есть ли usage-блок (input/output/cache-токены), поля
     sessionId, cwd, timestamp, model, признак сабагентского запроса;
   - публичные цены API Moonshot для моделей kimi-k2 (и других id, которые
     встречаются в наших данных): $/MTok input, output, cache read/write;
   - размер контекстного окна этих моделей.
   Каждый факт подтверждай источником (файл на диске с примером записи или URL).

2. Реализация (только если п.1 подтвердил данные):
   - src/pricing.ts: добавь цены kimi-* моделей в priceForModel (сейчас
     не-Claude id возвращают null) и окна в contextWindowTokens; если формула
     кэша у Moonshot отличается от anthropic-коэффициентов — сделай её
     явной для kimi-ветки, с комментарием-источником;
   - src/tokenUsage.ts: научи TokenScanner читать транскрипты Kimi (второй
     root-каталог), с тем же дедупом и инкрементальным чтением; если формат
     несовместим — отдельный парсер, но те же Bucket/ModelTotals;
   - тесты: расширь test/pricing.test.ts и test/tokenUsage.test.ts по образцу
     существующих (assert + временные файлы, без фреймворков).
   Если у Kimi Code транскриптов с usage нет — ограничься docs/KIMI-USAGE.md
   (зафиксируй это) и ценами моделей в pricing.ts.

3. Гейты: npm test и npm run lint зелёные. Каталог hooks/ не трогать.
   Комментарии в src — на английском, в стиле соседнего кода. Один коммит
   вида "feat: kimi token pricing/transcripts (research + impl)".
```
