# Грабли проекта AI Office

Живой каталог грабель (ADR-0001, пункт обратного потока 0.7 литании).
Ссылки — только слагами. Источник перенесённых инцидентов — мастер-копия
`prestart-litany.md` (read-only); новые проектные грабли дописываются сюда
сессиями и мигрируют в мастер-литанию.

Легенда статусов: **активна** — правило/гейт действует; **закрыта** —
грабля застрахована кодом или тестом; **принцип** — держим в голове,
машинной страховки нет.

## Версии и контракты

- `gotcha-version-sot` — **активна**. Несколько SoT версии расползаются.
  SoT версии — `package.json`, нигде больше руками не дублируется.
- `gotcha-version-symmetry` — **принцип**. Автовыравнивание версий между
  артефактами = фейковые релизы; бамп только по команде, по чеклисту.
- `gotcha-lexicographic-semver` — **принцип**. Строковое сравнение версий
  стреляет на MINOR=10; сравнивать версии только парсером, не строками.
- `gotcha-feature-test-debt` — **активна**. Фича изменила контракт
  (JSONL-схему) — оба скрипта, `eventParser.ts`, `HOOKS-DESIGN.md` §4 и
  тесты правятся в том же коммите (см. AGENTS.md).
- `gotcha-tsc-no-b` — **принцип**. `tsc` без `-b` не проверяет project
  references. Сейчас references не используются; при введении — гейт
  сборки обязан их покрывать.

## Windows и кодировки

- `gotcha-gitattributes` — **закрыта**. Без `.gitattributes` LF↔CRLF-дрейф
  ломает скрипты в Linux. Файл создан (sh/py/git-хуки — LF).
- `gotcha-non-ascii-toolchain` — **закрыта**. Не-ASCII/BOM в каналах
  тулчейна: stdin хуков читается BOM-толерантно (`utf-8-sig` / trim),
  флаг-файлы — тоже. Уже куснула — отсюда BOM-защита в скриптах.
- `gotcha-case-insensitive-headers` — **принцип**. Регистронезависимая ФС
  Windows: пути нормализуются только через `normPath`/`normcase`
  (см. `HOOKS-DESIGN.md` §8), не ручными сравнениями.
- `gotcha-exec-bit` — **принцип**. Скрипт без +x молча не исполняется;
  sh-файлы в `hooks/` коммитить с exec-битом.

## Данные и логика

- `gotcha-placeholder-data` — **активна**. Черновые значения без пометки
  уезжают как проверенные; плейсхолдеры маркируются (см. AGENTS.md).
- `gotcha-green-modules-dead-system` — **закрыта**. Модули зелёные, система
  мертва, если регистрация не покрывает событие: wiring-тест
  `test/hookWiring.test.ts` проверяет `event_type` скриптов ⊆ регистрации
  обоих CLI ⊆ события `src/types.ts`.
- `gotcha-orphan-config` — **принцип**. Конфиг-поле без потребителя рядом
  с хардкодом; новая настройка `aiOffice.*` без читателя — не коммитится.
- `gotcha-gitignored-dependency` — **принцип**. Зависимость от артефакта в
  .gitignore; страховка — CI «чистый клон стартует» (`npm ci` + сборка).

## Процесс

- `gotcha-docs-drift` — **активна**. Доки отстают молча; закрывается
  ритуалом закрытия сессии (см. AGENTS.md).
- `gotcha-god-files` — **активна**. God-файлы съедают контекст; порог
  400 строк и карта в AGENTS.md (Module Map).
- `gotcha-phantom-tails` — **активна**. «Незакрытые» пункты давно сделаны;
  статусы roadmap сверяются с кодом.
- `gotcha-silent-later` — **активна**. Молчаливое «потом» исчезает; всё
  отложенное — письменно.
- `gotcha-ci-wrong-branch` — **активна**. CI слушает рабочую ветку
  (`master`); смена модели ветвления = правка триггеров в том же коммите.
- `gotcha-hook-shell-blind` — **принцип**. Хук слеп к реальному шеллу:
  пользователи запускают CLI из Git Bash / PowerShell / cmd. Команды хуков
  строятся без shell-специфики (`buildHookCommand`), пути — через `$HOME`
  (Claude) и абсолютные в TOML literal string (Kimi).
- `gotcha-probe-self-trigger` — **принцип**. Фоновые пробы сами триггерят
  хуки (у ClaudeBar фоновый `claude /usage` порождал сессионные события —
  фильтруют по cwd пробы). Если появится фоновый опрос CLI — фильтровать
  его события так же, иначе дашборд покажет призрачные сессии.
- `gotcha-renumbered-parent` — **активна**. Перенумерация родительского
  документа ломает производные ссылки; ссылки только слагами.
- `gotcha-two-agent-configs` — **закрыта**. Две конфигурации агента
  рассинхронизировались бы неизбежно: одна точка входа правил (AGENTS.md),
  общие хук-скрипты, паритет py/js страхуется `emitAgentEvent.test.ts` +
  `emitAgentEventPy.test.ts`.
- `gotcha-automated-prompt` — **закрыта**. Системные инъекции неотличимы
  от промпта пользователя и не должны снимать аварийную остановку:
  `is_automated_prompt` / `isAutomatedPrompt` в обоих скриптах
  (списки маркеров — «Keep in sync», см. `HOOKS-DESIGN.md` §8).
- `gotcha-llm-stale-configs` — **активна**. Конфиги быстро меняющихся
  сервисов по памяти модели — ложь; сверка с актуальной документацией.
